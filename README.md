# CrewAI Grok Report Bot

**AI Report Generator using CrewAI and Grok AI**

This project demonstrates generating detailed reports and summaries on any topic using AI agents built with [CrewAI](https://github.com/crewai/crewai) and [Grok AI](https://grok.ai).

---

## Features

- Generate detailed structured reports from a topic.
- Summarize reports into concise paragraphs (<300 words).
- Uses Grok AI API for generation (100% Grok, no OpenAI required).
- Easy to run on Windows, Linux, or macOS.
- Console-based workflow (optionally extendable with a GUI).
